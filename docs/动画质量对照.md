# 200 AI 动画更新：画质对照与接入

[15 秒实机并排展示](https://ubik42.github.io/?work=lyra-performance-lab) · [相机与状态摘要](data/animation-quality.json)

本轮使用 UE 5.7.4，在两个独立编辑器进程中分别运行单机 PIE。两组均为 L_ShooterPerf、Seed 1337、200 个 AI 加 1 个本地角色，路径生成规则相同。角色资产、基础移动与动画沿用 Epic Lyra；负载、距离策略、采样与录制入口为本项目扩展。

## 策略对应的引擎状态

宿主 `ULyraSignificanceManager` 每 0.1 秒按视点距离更新重要度，顺序回调 `ALyraCharacter::ApplyAnimationLODSignificance`。自有插件依赖宿主接入，公开快照不包含完整 Epic 源码和资产。

| 对象 | 实际设置 |
| --- | --- |
| 本地角色或 1200 uu 内 | `bEnableUpdateRateOptimizations=false`，`AlwaysTickPose`，恢复原后处理开关 |
| 其他角色 | 启用 URO，`OnlyTickMontagesWhenNotRendered`；具体降频由引擎选择 |
| 2400 uu 外非保护角色 | `SetDisablePostProcessBlueprint(true)`，省去包含 FootPlant IK 的后处理 |
| 网格最低 LOD | 目标 2 按 `GetNumLODs()-1` 截断；本轮全部网格只有一个 LOD，仍为 LOD0 |

启用策略后动态关闭总开关不会自动恢复所有已经应用的状态，因此 A/B 采用独立进程，避免状态残留。

## 本轮实际观察

两组各四次快照均为 201 个角色、200 AI。基准组 URO 和后处理关闭数量均为 0。优化组近景镜头末尾，15 个角色保留完整更新，186 个启用 URO，102 个关闭后处理。启用 URO 者 UpdateRate 主要为 3，少量为 4；关闭 URO 的保护角色可能保留旧参数值，分析时必须先检查 URO 开关。

降低姿态更新密度并关闭足部贴地后处理会影响连续性与接地细节。当前为人群移动对照；快速动作、斜坡与阈值切换仍需专项观察。全部角色当前 LOD 为 0，不能宣称本轮存在网格减面收益。

## 录像条件

- 原生视口为 1591 × 843，两组分别记录 233 / 247 帧，约 18 秒游戏时间。
- 最终视频为全景 5 秒、近景 5 秒、第一段原帧局部裁切放大 5 秒。两次运行的角色轨迹不逐帧一致；按游戏时间回放，无插帧、无声。
- 第三个长焦机位被墙体遮挡，未纳入成片。其快照只保留为状态记录。
- 录帧开销影响运行速度，录像不用于计算 FPS 或性能收益。历史 2026-08-31 的 3+3 性能数据保留原版本、窗口和环境，见 [性能摘要](data/performance-results.json)。

## 开发录制入口

[PerformanceLabModule.cpp](../Plugins/PerformanceLab/Source/PerformanceLab/Private/PerformanceLabModule.cpp) 在非 Shipping 构建注册：

```text
PerformanceLab.Debug.SetView x y z pitch yaw roll fov
PerformanceLab.Debug.LogAnimation
```

SetView 创建或复用临时 CameraActor，改变玩家视点，不移动角色。LogAnimation 只读输出相机、角色数、距离、移动速度、URO、后处理、LOD 与更新率；不能在正式计时采样中调用。

使用具备 Lyra 5.7 宿主接入的开发工程，加载 `/ShooterCore/Maps/L_ShooterPerf`，Experience 为 `B_ShooterGame_Perf`。共同启动参数：

```text
-PerfLab -PerfLabAgents=200 -PerfLabSeed=1337
-PerfLabWarmup=5 -PerfLabDuration=120 -PerfLabReadyTimeout=180
-PerfLabPresetId=crowd-200-animation -PerfLabDimension=AnimationLOD
-PerfLabCrowdStateMachine -PerfLabNavigationLoad
```

优化组另加 `-PerfLabAnimationLOD -LyraCharacterAnimationLOD`。编辑器 Bot 覆盖设置需为 200，等待实际生成数达到 200 后录制。两组均使用 D3D12 和 `t.MaxFPS 30`。全景相机参数为 `-3200 -1800 500 -8 35 0 75`，近景为 `-2700 -1400 260 -2 35 0 65`。

本机自动录制通过已有 UELLMToolkit 桥接执行；该第三方桥接及其仅允许上述两条命令的白名单修改不在三个自有插件快照内。上述命令也可从开发控制台调用。纯公开覆盖层仍需宿主和项目资产，不能单独启动本场景。
