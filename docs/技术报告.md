# 技术报告

## 工程定位

项目在同一套 Lyra 5.7 工程中维护三个边界明确的模块：`HeroArena` 负责多人玩法，`PerformanceLab` 构造运行时负载并记录数据，`PerformanceWorkbench` 在 Editor 内编排实验和比较结果。游戏运行不依赖工作台，运行时采集模块也不依赖 Editor。

Epic Lyra 提供基础射击、队伍、GAS、Inventory/Equipment、控制点机器人和内容资产。本项目新增英雄规则、能力实现、比赛模式、性能压力场、采集指标与编辑器工具，并在必要位置通过 Lyra 的 Game Feature 和组件扩展点接入。

## 五英雄多人游戏

英雄选择以服务器状态为准。客户端提交 Hero ID，服务器校验后在 PlayerState 保存选择，并在 Pawn 初始化、死亡重生和换人时装配或撤销 Ability Set 与装备。终极能量由有效伤害、治疗、击杀和助攻产生，拥有者单独接收复制；切换英雄清空，死亡保留，释放后归零。

五名英雄共享同一套选人和生命周期，不为每名英雄复制 Pawn 与模式代码。差异主要由 Hero Definition、Ability Set、武器和 Gameplay Tag 组成。当前已接入轮换控制点、战场脉冲和团队淘汰，均可使用五英雄阵容与 5v5 职责机器人。

机器人继续使用 Lyra 控制点行为树处理移动、寻路、索敌和射击；Hero Arena 在其上增加按职责触发的技能决策。这样可以复用 Lyra 已有战斗负载，同时把项目新增部分限制在英雄与模式规则内。

## 多角色性能实验

正式对比固定引擎版本、源码提交、地图、Experience、人数、随机种子、分辨率、RHI、画质、镜头、预热与采样时长。网络实验还固定服务器/客户端拓扑。每组使用三次 Baseline 与三次 Optimized，报告中位数、P95 和样本范围。

性能数据之外，实验同步记录角色存活与移动、目标获取、路径请求与到达、近景动画质量、光追/阴影生效数量、特效事件和网络连接。只有两组运行的实际负载接近时，结果才进入聚合。

### 已采用的调整

- AI：把 200 个 Pawn 的重复目标扫描收敛为共享战场事实。目标发现决策平均中位数由 0.1392 降至 0.0240 ms/帧，目标获取和主要状态分布保持接近。
- Navigation：保留独立寻路，通过目标合并和重规划冷却减少重复请求；路径请求约下降 82%，整帧均值与 P95 约下降 1.7%。
- Animation / IK：使用 UE 原生 Update Rate Optimization、可见性 Tick 策略和 Skeletal Mesh LOD；2400 uu 外的非本地角色省略 FootPlant Post Process AnimBP。Animation 平均中位数由 15.18 降至 10.99 ms。
- Rendering：1500 uu 外的非本地角色退出 Ray Tracing Scene，光栅主通道、动画和阴影保持。动态光追几何平均中位数由 4.02 降至 2.50 ms；GPU 总平均基本持平，因此不将前者扩写为整帧 GPU 收益。
- Networking：Relay 部署物按连接相关性复制，服务器出站带宽约由 20.7 降至 17.7 KB/s，复制阶段约由 1.94 降至 1.60 ms。
- VFX / UI：持续 Niagara 生命周期、武器表现距离预算和战术 HUD 10 Hz 更新已形成稳定的局部指标下降；只有整帧同时变化的案例才报告 Frame 收益。

### 未接入默认游戏的候选

Chaos 距离 LOD 在现有 300 刚体场景中的主线程均值没有改善；角色阴影候选受可见集合变化影响；动态战斗 Niagara 方案改变了实际事件率。上述记录仍保留，但不作为默认优化或公开收益。

## 性能工作台

`PerformanceLab` 在运行时创建压力、记录元数据与场景状态；`PerformanceWorkbench` 负责进程启动、结果索引、聚合和显示。两者用 JSON Preset 与结果文件连接。

工作台现有 14 条中文轨道，分为真实 5v5、受控子系统负载和 200 角色压力场。它可以连续启动 ABBAAB 六次采集，也可以编排 Dedicated Server 与两个 Client。每条轨道直接显示主要 A/B 指标、前后值、变化率和范围重叠；时间轨道列出 CPU、工作线程、Render Thread 与 GPU Pass 的主要开销。Niagara 实验还会读取逐 System 数据，继续定位到具体资产与 Owner。

工作台不替代 Unreal Insights、CSV Profiler 或引擎自带统计，而是补齐固定运行条件、批量启动、结果归档和跨样本比较这一层。

## 当前边界

- 当前截图和数字来自 Windows 11、UE 5.7.4（CL 51494982）、Lyra 5.7 以及本机固定场景，不能外推到其他项目与硬件。
- 公开仓库不包含 Epic 二进制资产，不能作为独立可运行的 Lyra 分发包。
- Gameplay 下一步主要处理机器人技能时机、英雄反制与对局反馈；性能方向只继续处理实际 Profile 中出现的新热点。
